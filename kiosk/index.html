Κλείδωμα tablet παρουσιολογίου

Για υπεύθυνο STORE 311 / Le Jardin. Η εφαρμογή δεν μπορεί μόνη της να κλειδώσει Home / Πρόσφατες εφαρμογές — χρειάζεται καρφίτσωμα Android (ή kiosk browser).

Σημαντικό: πρώτα εγκαταστήστε ως εφαρμογή από Chrome/Edge, μετά καρφιτσώστε. Το web «Πλήρης οθόνη» δεν αντικαθιστά το καρφίτσωμα.

1. Εγκατάσταση ως εφαρμογή

  1. Ανοίξτε στο Chrome/Edge το URL του μαγαζιού (δείτε κάτω).
  2. Μενού ⋮ → Εγκατάσταση εφαρμογής ή Προσθήκη στην αρχική οθόνη.
  3. Ανοίγετε μόνο από το εικονίδιο (όχι από καρτέλα browser).
  4. Αν φαίνεται Πλήρης οθόνη μέσα στην εφαρμογή, πατήστε το.

2. Καρφίτσωμα οθόνης (Screen pinning)

Ενεργοποίηση μία φορά στις Ρυθμίσεις:

  1. Ρυθμίσεις → αναζητήστε Καρφίτσωμα / Screen pinning / App pinning.
  2. Ενεργοποιήστε το. Αν υπάρχει «Ζήτα ξεκλείδωμα πριν το ξεκαρφίτσωμα», ανοίξτε το.

Κάθε βάρδια / μετά από επανεκκίνηση:

  1. Ανοίξτε το παρουσιολόγιο από το εικονίδιο.
  2. Ανοίξτε τις Πρόσφατες εφαρμογές.
  3. Στο κάρτο της εφαρμογής → εικονίδιο εφαρμογής ή παρατεταμένο πάτημα → Καρφίτσωμα / Pin.

Ξεκαρφίτσωμα (μόνο υπεύθυνος): συνήθως παρατεταμένο πάτημα Πίσω + Επισκόπηση, μετά PIN / μοτίβο.

3. Αν το pin δεν φτάνει

ΕργαλείοΣημείωση
Fully Kiosk Browser Start URL = η εφαρμογή· ενεργοποιήστε kiosk / lockdown.
MDM / Knox / Lock task Εταιρική διαχείριση συσκευής — όχι από την ιστοσελίδα.

4. Γρήγορη λίστα

  1. Εγκατάσταση από Chrome → εικονίδιο
  2. Άνοιγμα από εικονίδιο
  3. Καρφίτσωμα οθόνης
  4. Προσωπικό: ΣΗΜΕΡΑ → πόστο → ΑΦΙΞΗ / ΑΠΟΧΩΡΗΣΗ
  5. Ξεκαρφίτσωμα μόνο με PIN υπεύθυνου
