# Εισαγωγή ωρών tablet → ΜΙΣΘΟΔΟΣΙΑ

**Προτεινόμενο για καθημερινή χρήση:** άνοιξε τη σελίδα  
https://papadonikolakisgiannis73-maker.github.io/Attendance-log/misthodosia/  
(χωρίς εγκατάσταση — JSON + `.xlsx` → κατέβασμα).

Αυτός ο φάκελος έχει το **offline εργαλείο Python** (και remap ΚΑΤΑΛΟΓΟΥ). Διαβάζει εξαγωγή μήνα (JSON/CSV) από το tablet και γράφει ώρες στο φύλλο μήνα του `ΜΙΣΘΟΔΟΣΙΑ 2026.xlsx` **ανά κωδικό εργαζομένου**, όχι ανά θέση στήλης.

## Εγκατάσταση

```bash
cd payroll-import
pip install -r requirements.txt
```

## Ροή (όπως τα ποτά)

1. Στο tablet: **Μήνας** → **JSON μισθοδ.** (ή Excel/CSV).
2. Αντιγραφή του αρχείου στον υπολογιστή.
3. Τρέξιμο εισαγωγής σε **αντίγραφο** του workbook:

```bash
python import_hours.py \
  --xlsx "/διαδρομή/ΜΙΣΘΟΔΟΣΙΑ 2026.xlsx" \
  --export parousiologio-month-2026-11.json \
  --out "/διαδρομή/ΜΙΣΘΟΔΟΣΙΑ 2026-με-ώρες.xlsx"
```

4. Άνοιγμα του νέου xlsx → φύλλο μήνα → ώρες στα σωστά ονόματα.

## Χειροκίνητα overrides

- Μετά την εισαγωγή μπορείς να αλλάξεις οποιοδήποτε κελί (π.χ. να μη βάλεις ρεπό / να σβήσεις ώρα).
- Στο επόμενο import (χωρίς `--force`): το script συγκρίνει τα κελιά με την τελευταία εισαγωγή· ό,τι άλλαξες μένει (**Κλειδωμένο** στο κρυφό φύλλο `_IMPORT_META`).
- Για να ξαναγράψει όλα από το tablet: πρόσθεσε `--force`.

## Προσθήκη / αφαίρεση ατόμου χωρίς μπέρδεμα

Το Excel δείχνει ονόματα από τον **ΚΑΤΑΛΟΓΟ** με τύπο· οι ώρες όμως κάθονται σε **στήλες**. Αν αλλάξεις σειρά στον ΚΑΤΑΛΟΓΟ, τα ονόματα μετακινούνται αλλά οι ώρες μένουν στη στήλη → μπέρδεμα.

**Σωστή διαδικασία:**

```bash
# 1. ΠΡΙΝ αλλάξεις τον ΚΑΤΑΛΟΓΟ
python import_hours.py --xlsx ΜΙΣΘΟΔΟΣΙΑ.xlsx --remap-snapshot

# 2. Άλλαξε ΚΑΤΑΛΟΓΟ (νέος κωδικός / Ενεργός=ΟΧΙ) και αποθήκευσε στο Excel

# 3. Επαναφορά ωρών στις νέες στήλες ανά κωδικό
python import_hours.py --xlsx ΜΙΣΘΟΔΟΣΙΑ.xlsx --remap-apply
```

Μην σβήνεις γραμμές από τη μέση των ημερήσιων πινάκων του φύλλου μήνα — μόνο ΚΑΤΑΛΟΓΟΣ.

## Επιλογές

| Επιλογή | Νόημα |
|--------|--------|
| `--force` | Ξαναγράφει και τα χειροκίνητα |
| `--dry-run` | Δοκιμή χωρίς αποθήκευση |
| `--month N` | Μήνας αν δεν φαίνεται στο αρχείο |
| `--mark-locks` | Μόνο σήμανση χειροκίνητων |
| `--prepare --out …` | Αντίγραφο με φύλλο `_IMPORT_META` |

Δείγμα: `sample/parousiologio-month-2026-11.json`
